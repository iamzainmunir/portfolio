# Zain Munir - Software Architect

Source for my personal portfolio: a single-file, dependency-free site with light and dark
themes and an animated system-architecture diagram (microservices, CQRS, event-driven, AI).

## Run locally

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

Or just open `index.html` in a browser.

## Deploy (GitHub Pages)

Enable GitHub Pages on the `master` branch (root). The site is static, with no build step.

## Structure

- `index.html` - the whole site (HTML, CSS and JS inline)
- `assets/img/` - project and profile images
- `assets/Zain-Munir-Resume.pdf` - resume
